# 🏐 Danny 排球分組小工具 (Volleyball Team Shuffler)

芳和實中（每週二 17:45-20:45）排球請假與臨打隨機分組系統。

## 🌟 功能特色
1. **Google Sheets 即時同步**：自動讀取 Google 表格中的季打請假與臨打名冊。
2. **自動判定最接近場次**：自動比對系統時間，預設鎖定最接近的週二場次（如 11/03），亦可自由切換其他日期。
3. **智慧性別推斷**：名字未標註性別時（如臨打），自動依據常見姓名庫與特徵字智慧判定性別，且提供點擊一鍵手動切換。
4. **男女比例均衡隨機分組**：依據相同男女比例洗牌隨機分成 5 組，保證每組戰力與男女搭配最均衡。
5. **一鍵複製結果**：格式化排版，點擊即可複製並直接貼上至 LINE 或 Telegram 團隊群組。
6. **支援臨時增修**：支援臨時球員新增與自訂出席勾選。
